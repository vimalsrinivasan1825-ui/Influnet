**Code changes** (all in working tree, not committed):

All 5 admin API routes (`businesses`, `collabs`, `dashboard`, `projects`, `users`) refactored onto it, removing ~150 lines of duplicated auth boilerplate and fixing the fact that admin routes previously ran with the *authenticated* client, which now can't see email/phone (would have silently broken the admin user list).

- `apps/web/src/lib/validators.ts` — added `UsernameSchema` (format + reserved-word blocklist: admin, api, dashboard, login, settings, etc. — stops someone claiming `/c/admin`). Applied to all 3 places username is validated.
- `apps/web/src/app/api/conversations/route.ts` — removed `email` from two profile selects (was leaking counterparty emails into the messages UI's API response).
- Open-redirect guard added to the `next` query param in `login`, `signup`, `signup/business`, `signup/influencer` — previously `?next=https://evil.com` would work after login.
- `apps/web/src/app/reset-password/page.tsx` (new) — full forgot/reset password flow (email request form + new-password form + expired-link handling). This closes a **live broken link** — the login page already links to `/reset-password` but the page didn't exist (404).

- `apps/web/src/app/api/collabs/route.ts` — duplicate pending-request insert now returns 409 with a clear message instead of a raw 500.
- `apps/web/src/lib/api-client.ts` (new) — `getAuthToken()` (always reads the live Supabase session, never localStorage) and `apiFetch()` (safe JSON parsing — fixes the exact "Unexpected end of JSON input" class of bug from earlier in this session).
- Removed all `localStorage.getItem('influnet_token')` / `setItem` usage across `login`, both `signup` pages, `dashboard/shell.tsx`, `dashboard/requests/page.tsx`, and `store/auth-store.ts`.
