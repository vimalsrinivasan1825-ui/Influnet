The journey — initial stage to now

Three generations of the product, and everything shipped since.

  • Gen 1 · June 2026

    Static site on Firebase

    Marketing site + a compiled React bundle served by Firebase Hosting, with Supabase bolted on through a runtime auth bridge that intercepted /api/* calls. Included an early public creator profile and phone-OTP UI.

  • Gen 1.5 · June–July 2026

    The patch era

    Source access to the bundle was lost — ~60 Node/PowerShell scripts patched the compiled JavaScript directly. Painful, fragile, and the reason for the rewrite.

  • Gen 3 · early July 2026

    Next.js rewrite begins (influnet-app)

    Fresh Next.js 16 + Supabase app: premium landing page, login, both 4-step signup wizards, bento-grid dashboards.

  • July 7, 2026

    Backend build-out

    API routes for collabs, conversations, projects, discovery, dashboards. Unidirectional request rule, auto-created projects + conversations on accept, the 12-stage pipeline, admin panel (approvals, users, oversight), settings wiring, E2E matchmaking test.

  • July 8–9, 2026

    Kanban workspace + Stream Chat

    Per-project Kanban board with draggable cards (migrations 039–041); messaging UI migrated from Supabase Realtime to Stream Chat.

  • July 10, 2026

    Full audit & work order

    Complete codebase analysis (docs/PROJECT_ANALYSIS.md) found the broken messaging auth, a raw-SQL route, secrets in git, and the missing notification pipeline. Phased fix plan written (.agents/EXECUTION_PLAN.md).

  • July 10, 2026

    Phase 0 — stabilization

    Env files untracked, .env.example added, ~13,400 lines of pending work committed in reviewable chunks. Key rotation flagged for human action.

  • July 10, 2026

    Monorepo refactor

    Turborepo + npm workspaces: app moved to apps/web, ~21,900 legacy files deleted (preserved at git tag legacy-archive), CI updated, cached builds verified.

  • July 10, 2026

    Phase 1 — core logic fixes (Tasks 1.1–1.5)

    Stream Chat auth fixed with channel-membership checks · raw-SQL conversation route replaced by RPC · atomic accept RPC · /api/notifications/summary + live bell counts · shared withAuth helper + snake_case Zod validation on every route.

  • July 10, 2026

    Missing RPCs discovered & created

    Live-DB verification revealed the two RPCs the routes call were never actually created. Migration 043 written and applied — accepting a request now works end-to-end. Buy-vs-build and OTP-reuse decisions recorded in docs/DECISIONS.md.

  • Next

    Ship the core promise

    Task 1.6 message persistence → Task 2.1/2.2 instant notifications (Realtime + email) → Task 2.3 public link-in-bio profile → password reset, OTP UI, then depth (search, analytics, deliverables) and Phase 3 payments.
