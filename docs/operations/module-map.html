The deepest module, drawn out

How a project comes to exist, and the three shapes it can take

There are three ways a deal starts, and all of them end up in the same place: an accepted request and a 1-to-1 conversation. Accepting a request only opens the chat; it does not create a project. Terms are agreed in the chat, then both sides accept a proposal, and that creates the project. The proposal fixes which of the three flows the project runs.

What “make it strong” means

The hardening loop: seven steps for every unit

Run the same seven steps on every unit you pick. A unit counts as strong only when every check on its finish line passes. The explorer tracks that for you.

  1. Map itList its screens (web and phone), API routes and tables. The explorer already has a first draft; correct it where the code disagrees.
  2. Walk itUse it by hand as a creator and as a brand, on web and on a phone, the way a new user would. Write down every confusing moment.
  3. Break itWrong role, two people clicking at once, a vendor switched off, slow network, empty and huge inputs, a blocked user, the Free plan limit.
  4. Lock itAdd an E2E or unit test that fails if the unit regresses. Tests must assert the correct behaviour, not reproduce the bug.
  5. Match itThe phone does what the web does, with the same wording, limits and errors. Differences are decided on purpose, not left by accident.
  6. Watch itErrors from this unit reach Sentry, its main action is a PostHog event, and admin can see its state.
  7. Sign it offTick every finish-line check, add one line to the module's log, and only then move to the next unit.

One unit in focus

Only one unit is “in focus” at a time; the explorer enforces it. Bugs found elsewhere go on a list, not into this unit's work.

Finish downward, not sideways

Finish every unit in an area before starting the next area, and every area in a module before the next module.

Fix it at the source

If a unit's fix belongs in packages/core or the database, fix it there once. Web and phone then get it together.
